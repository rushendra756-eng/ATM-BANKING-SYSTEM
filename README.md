# ATM-BANKING-SYSTEM
Beginner python project simulating project an ATM with PIN verifications, deposits, withdrawals and a mini statement.
 ATM Banking System

**About the Project**

This is a beginner-level Python console application that simulates basic ATM operations.

 **Features**

* PIN verification with limited attempts
* Check account balance
* Deposit money
* Withdraw money with balance validation
* Mini statement
* Track successful and failed transactions

** Technologies Used**
* Python
* Conditional statements
* While loops
* Variables and operators
* User input and validation

** How to Run**
1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:
python atm.py

**Learning Purpose**
Created as a hands-on project while learning Python programming.
**Note:** This is an educational simulation, not a real banking application.
